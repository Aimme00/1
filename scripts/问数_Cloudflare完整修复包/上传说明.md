# Cloudflare 修复包上传说明

请在 GitHub 仓库根目录中保持以下路径，并同时替换 4 个文件：

- `web/index.html`
- `web/styles.css`
- `web/app.js`
- `scripts/verify-cloudflare.mjs`

不要只替换 `web/index.html`，也不要把“问数_Cloudflare完整修复包”这一层文件夹上传到仓库。

提交后 Cloudflare Pages 会根据新提交自动重新构建。请查看新提交对应的部署，不要重试旧的失败部署。
